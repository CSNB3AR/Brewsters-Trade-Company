# Discord Server Layout

## THE CHARTER
- `#welcome-and-charter`: rules
- `#company-notices`: announcements
- `#join-the-company`: hiring pitch, fame requirement stated here

## DISPATCH (Route Running)
- `#dispatch-board`: Forum channel, see `dispatch-board-rules.md`
- `#the-ledger-log`: route payouts and splits recorded here (see `operations/ledger-log.md` for the actual tracker)

## THE WORKSHOP
- `#order-board`: material needs, crafting requests

## THE GUARD (PvP)
- `#muster`: Crystal League / Hellgate / Corrupted Dungeon sign-ups
- `#the-pit`: Arena Night + betting pool

## THE TAVERN (Community)
- `#common-room`: general chat
- `#trophy-wall`: clips/highlights, doubles as a content feed

## THE BOARD ROOM (Officers only)
- `#officer-chat`
- `#the-vault`: Quartermaster's financial tracking

## Voice Channels
- The Tavern (general)
- Muster Point (PvP ops)
