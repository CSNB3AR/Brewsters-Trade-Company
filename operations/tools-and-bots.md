# Tools and Bots

Market-price Discord bot options for the guild server, useful groundwork before building a custom bot.

## Primary Recommendation

**Albion Online Market BOT** (top.gg), built on the Albion Online Data Project (AODP) API.
- Supports `/price` with city filtering, including Caerleon and the Black Market.
- Multilingual.

## Backup Option

**Albie**: same core function, different command style.

## Known Dependency Risk

Both bots depend on AODP's data feed, which has broken temporarily in the past when Sandbox Interactive changed price encryption. This is a known dependency risk, not a sign of either project being abandoned.

## Custom Bot

A custom bot is planned separately to bring things "up to snuff" (dispatch board automation, ledger logging, etc.). Not started yet, this file just covers what to use in the meantime.
