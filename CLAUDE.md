# CLAUDE.md

Guidance for Claude Code sessions working in this repo.

## What This Project Is

This is not a software project. It's the planning and operations documentation for Brewster's Trade Company, an Albion Online guild, plus the user's own character playbook. There is no code to build or test here. Changes are edits to markdown files.

See `README.md` for the full file index before assuming something needs to be created, most topics already have a home.

## Standing Preferences

- No em dashes in any response or written content.

## Working Conventions

- Items noted as "undecided" or "open" (see `README.md`'s Open Items section) should stay undecided until the user actually makes a call. Don't resolve them unilaterally.
- When the user shares new planning decisions, update the relevant existing file rather than creating a new one, unless the topic genuinely doesn't fit any existing file.
